# Try PermitsNJ in your browser

This option needs no Python, Node.js, or other development software installed on your Windows computer. It runs the demonstration in GitHub Codespaces using your GitHub account.

1. Open [the project on GitHub](https://github.com/Unicorse13/My-First-Testing), sign in, and select the **main** branch. Click the green **Code** button, choose **Codespaces**, then **Create codespace on main** (or the **+** button). Leave the default options selected. Your account needs Codespaces access and available usage allowance.
2. Wait for the initial setup to finish. The application should open in a new browser tab automatically. If it does not, select the **Ports** tab in the browser editor and click the globe / **Open in Browser** icon beside **8000 — PermitsNJ**. Keep the port's visibility **Private**.

On the application sign-in screen, click **Enter demo workspace** to use the administrator account. You can choose other demonstration roles from the same screen. No terminal commands are required for this setup.

Try creating a permit, confirming prior approvals, submitting it for review, recording a plan review, making mock payments, scheduling an inspection, and generating a demonstration certificate. Use fictional information only. No real money is collected.

Your test records stay in that codespace when you stop and restart it. Deleting the codespace deletes its local test database. When finished, visit [Your codespaces](https://github.com/codespaces), open the menu beside this codespace, and choose **Stop codespace**. You can return there to resume it later.

If GitHub reports that Codespaces is unavailable or your work network blocks it, share the message so a different testing route can be selected.

The repository contains automatic setup and startup configuration. A running hosted codespace and its browser URL are created only when you complete the GitHub step above; this document does not establish that a hosted instance has already been created or verified.

The historical reference guides and implementation limits are documented in [REFERENCES.md](REFERENCES.md) and [IMPLEMENTATION.md](IMPLEMENTATION.md).
